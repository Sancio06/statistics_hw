1. Toy ECC Encryption & Decryption Scheme

Using our toy curve $y^2 = x^3 + 7 \pmod{17}$ with $G = (1, 5)$, we implement an ECIES-style point-masking scheme:

  • Recipient Keypair: Private key $k_B$, Public key $Q_B = k_B G$.
  • Encryption: To encrypt a scalar $m \in [1, 16]$, Alice picks ephemeral key $r=3$. She outputs $C_1 = r G$ and $C_2 = m \cdot (r Q_B)_x \pmod{17}$.
  • Decryption: Bob recovers shared secret $S = k_B C_1 = r Q_B$ and computes $m \equiv C_2 \cdot (S_x)^{-1} \pmod{17}$.

2. The Caesar Cipher

The classical Caesar cipher is a symmetric substitution cipher where each letter in plaintext is shifted by key $K \in [0, 25]$: $$E(p) = (p + K) \bmod 26, \quad D(c) = (c - K) \bmod 26$$

3. Comparative Analysis: Toy ECC vs. Caesar Cipher

Encryption & Keys

Caesar: Symmetric (shared secret key).
Toy ECC: Asymmetric (public key encrypts, private key decrypts).

Key Space Size

Caesar: $\vert{}\mathcal{K}\vert{} = 25$ (trivial to brute-force).
Toy ECC: Small field $p=17$, but real secp256k1 has $\vert{}\mathcal{K}\vert{} \approx 2^{256}$.

Statistical Properties

Caesar: Preserves language letter frequency.
ECC: Ephemeral random mask $r$ hides frequency patterns.

4. Statistical Cryptanalysis of the Caesar Cipher

We recover the shift key by comparing ciphertext frequencies with standard English letter distribution using Chi-Square ($\chi^2$) goodness-of-fit: $$\chi^2(k) = \sum_{i=0}^{25} \frac{(f_i - e_i)^2}{e_i}$$

Discussion: Toy Scheme vs Real secp256k1

  • Structural Attack Difference: Caesar cryptanalysis exploits natural language redundancy. ECC brute-force attacks exploit a small numerical search space.
  • Scalability in Full ECC: Real secp256k1 key space is $2^{256} \approx 10^{77}$. Exhaustive search is computationally impossible.
  • Toy Model Flaws: Small prime fields ($p=17$) are vulnerable to brute force and Pollard's rho algorithms. Real curves require large prime order subgroups.
