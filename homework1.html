1. Theoretical Background

In Ethereum and Bitcoin, public keys are derived from private keys via scalar multiplication on the secp256k1 curve ($y^2 = x^3 + 7 \pmod p$). Because the discrete logarithm problem on elliptic curves (ECDLP) is computationally intractable, calculating $Q = kG$ from $k$ is fast, but recovering $k$ from $Q$ is virtually impossible.

In this assignment, we demonstrate this principle using a simplified toy curve over the finite field $\mathbb{F}_{17}$:

$$y^2 \equiv x^3 + 7 \pmod{17}$$
  • Base Point ($G$): $(1, 5)$
  • Private Key ($k$): $6$
  • Public Key ($Q$): $Q = kG = 6G$

2. Elliptic Curve Arithmetic over $\mathbb{F}_p$

To add points $P = (x_1, y_1)$ and $R = (x_2, y_2)$ on $y^2 = x^3 + a x + b \pmod p$:

POINT ADDITION ($P \neq R$)

$$\text{Slope } s \equiv \frac{y_2 - y_1}{x_2 - x_1} \pmod p$$

Used when adding two different points

POINT DOUBLING ($P = R$)

$$\text{Slope } s \equiv \frac{3x_1^2 + a}{2y_1} \pmod p$$

Used when adding a point to itself

NEXT POINT $(x_3, y_3)$

$$x_3 \equiv s^2 - x_1 - x_2 \pmod p$$ $$y_3 \equiv s(x_1 - x_3) - y_1 \pmod p$$

These coordinate formulas apply to both cases once the slope $s$ is found. Note that $p = 17$ and $a = 0$ for our curve.

Cryptographic Discussion

1. Uniformity & Frequency of Coordinates:

On a finite field $\mathbb{F}_p$, scalar multiplication produces discrete points that appear pseudo-randomly distributed over the curve's valid subgroup. However, not all $(x, y)$ values in $[0, p-1]$ exist because $x^3 + 7 \pmod p$ must be a quadratic residue for $y$ to exist.

2. Avalanche Effect & Input/Output Correlation:

Unlike cryptographic hash functions (e.g., SHA-256), elliptic curve scalar multiplication $Q = kG$ preserves an underlying algebraic group structure: $$ (k_1 + k_2)G = k_1 G + k_2 G $$ This homomorphism means $Q$ does not exhibit a true random avalanche effect. Small changes in $k$ do not randomly scatter bits; instead, they follow deterministic group addition rules.

3. One-Way Function vs. Hash Function:

  • Elliptic Curve ($k \to kG$): Acts as a trapdoor one-way function based on ECDLP. It maps a scalar to a point on a specific group structure, making it ideal for asymmetric key generation and digital signatures.
  • Cryptographic Hash Function: Designed for pre-image resistance, second pre-image resistance, and collision resistance with maximum bit diffusion and strict avalanche behaviour, mapping arbitrary inputs to fixed-size bitstrings without preserving algebraic structure.
